---
name: Google Search Console verification
description: The successful ownership verification method for the Mandarin Garden website.
---

The Mandarin Garden site was verified in Google Search Console using a homepage HTML meta tag. Do not add or change DNS records for this URL-prefix verification method.

**Why:** The production site serves the published meta tag on both the custom domain and the Replit fallback domain, and the user confirmed Google accepted the verification.

**How to apply:** If Google issues a replacement token, update the homepage meta tag, republish, confirm the live HTML contains it, then complete verification in Search Console. Never store the token in project memory.
